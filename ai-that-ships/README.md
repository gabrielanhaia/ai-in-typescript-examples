# Book 5 — AI That Ships

*Evals, Guardrails, Cost Control, and Deploying AI Agents on Node.js*

Code for **Book 5** of [AI in TypeScript](../README.md) by Gabriel Anhaia.

**What the app becomes here:** it is measured, guarded, and deployed.

**What this book covers:** everything after it works — evals, guardrails, reliability, cost control, deployment on Node.

## Status

Not published yet. This directory fills in as the book is drafted — each chapter's example arrives as its own folder with a README stating what it does, the exact command to run it, and the output to expect.

## Running these examples (once published)

```bash
cp ../.env.example ../.env    # then add your API key
docker compose run ai-that-ships ch03  # from the repo root
```

You do **not** need to have run the previous book's examples. This directory is a self-contained snapshot of the app at this rung.
